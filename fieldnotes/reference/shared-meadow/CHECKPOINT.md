# Shared meadow — first cumulative checkpoint

This is the stable starting source for the fieldwork guide. It retains the
first supply/competition API and complete worked modules while the continuing
reference in `learning/ecosystem` grows. `fieldwork.py prepare` copies this
checkpoint to a new learner directory and never updates an existing attempt.

The source is course-owned original Rust. Its existing nineteen acceptance
checks are also retained unchanged in the continuing reference. Later arcs
extend the same learner copy through explained edits; they do not replace it.
