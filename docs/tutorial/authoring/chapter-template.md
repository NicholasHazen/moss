# Chapter template

[Authoring guide](README.md) · [Reader guide home](../README.md)

Copy this structure only for a useful new increment. Replace placeholders,
resolve destination-relative links and remove drafting instructions. Follow the
authoring contract for evidence and preserve existing filenames/anchors.
Before drafting, identify the useful ability this edit practices and the
earlier idea it reuses. The [progression reference](progression.md) guides that
choice; do not turn it into a learner checklist. Adapt this structure to the
explanation rather than assigning every page the same ceremony.
