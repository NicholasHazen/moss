# Context shelf

[Guide home](../README.md) · [Current task](../../../NOW.md) · [Project docs](../../README.md)

Use these pages when a piece of Moss feels unfamiliar. They keep the same
animals, values and files as the coding chapters, so each detour leads back
to something you can point at in the project.

- [Follow one Step through Moss](a-tick-through-moss.md) connects the browser
  button, ECS schedule, changed reserve and test assertion.
- [Rust at the point of use](rust-at-point-of-use.md) explains modules, public
  paths, borrowing and query loops.
- [Read a test as a small experiment](reading-a-test.md) explains the existing
  maintenance test, its query and literal expectations; its
  [failure guide](reading-a-test.md#find-out-how-far-the-run-got) distinguishes
  compiler errors, an unfinished helper and a failed comparison.
- [ECS through Fern and Flint](ecs-in-moss.md) separates individual data from
  shared rules and shows what a query asks the world to supply.
- [Attributes and defaults](attributes-and-defaults.md) explains templates,
  individual overrides and access to growing sets of data.
- [From a meal to an ecosystem](from-meals-to-ecosystems.md) connects finite
  food to later growth, daylight and population experiments.
- [The learning path](learning-path.md) connects possible future behaviors
  to the Rust/ECS concepts they introduce, without assigning new tasks.

None is prerequisite reading. For opening the preview or running a test, use
[the RustRover reading page](../reading-in-rustrover.md).
