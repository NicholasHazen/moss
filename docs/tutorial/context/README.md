Use these pages when a piece of Moss feels unfamiliar. They keep the same
animals, values and files as the coding chapters, so each detour leads back to
something you can point at in the project.

- [Follow one Step through Moss](a-tick-through-moss.md) connects the browser
  button, ECS schedule, changed reserve and test assertion.
- [Rust at the point of use](rust-at-point-of-use.md) explains the syntax that
  appears around those changes, including borrowing and query loops.
- [ECS through Fern and Flint](ecs-in-moss.md) separates individual data from
  shared rules and shows what a query asks the world to supply.
- [From a meal to an ecosystem](from-meals-to-ecosystems.md) connects the next
  rules to later growth, light, weather and population experiments.

None is required reading before Chapter 1A. If the immediate question is how
to open a preview or run a test, use [the RustRover reading page](../reading-in-rustrover.md).
